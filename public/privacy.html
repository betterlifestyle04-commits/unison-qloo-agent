Privacy & transparency

TRUST / HOW UNISON HANDLES DATA

Understand what you share.

UNISON is a public hackathon prototype. It doesn't require an account. You control when to use the live Qloo service and when to save or share a group plan. This page explains the difference.

What happens to the group brief?

When you generate a plan, your browser sends the group names, cultural favorites, and selected constraints to UNISON's server. The application processes the request to return recommendations. The application code does not store completed group briefs in a database. Hosting and infrastructure providers can nonetheless collect request metadata and operational logs.

The optional Taste Inspiration panel is a local collection of manually selected public cultural references. Searching and selecting examples modifies the form only and does not make Qloo requests. These labels are not official Qloo entity matches, and they are not automatically shared until a plan is generated or a link is explicitly copied.

In demo mode, UNISON uses fictional, deterministic recommendation evidence. In live mode, UNISON uses a server-only Qloo API key. Qloo receives selected cultural search terms, entity IDs, and relevant city or price constraints. Participant names are not deliberately included in Qloo API request parameters.

When is data kept on your device?

UNISON stores group briefs and recommendation summaries in your browser's localStorage only if you click “Save on this device.” Saved plans can include names, favorites and Qloo entity IDs. These records are not encrypted; other people using the same browser profile might view them. Use Delete to remove a saved plan from this browser. You can also clear site data in your browser settings.

Manual library backup: “Export backup” downloads a readable, unencrypted JSON file containing all explicitly saved briefs and summaries. It can include participant names, favorites, selected Qloo entity identifiers, and recommended option names. Only import files you trust. “Import backup” validates the format and adds plans only when there is space; it does not replace existing plans or submit requests to Qloo. Keep backups safe and delete any copies you no longer need.

Personal workspace: The My Workspace dashboard computes plan counts, average group size, city mentions, and recurring cultural references directly from plans already saved in this browser. It makes no additional Qloo calls and does not transmit dashboard data to the UNISON server. Choosing “Open brief” transfers a normalized brief temporarily via this tab's session storage, not a public URL fragment, and opens the planner in demo mode without automatically generating a result.

Group votes are temporary, local to the current page session, and aren't authenticated. They are not automatically synchronized between devices.

Optional expectation and after-outing experience ratings stay only in the current browser page memory. They are not transmitted to the UNISON server, Qloo, or an analytics provider. A person can explicitly download an anonymous participant-number CSV; it does not contain group names or cultural preferences. Ratings and matching context disappear when the page is refreshed or closed. Do not interpret this worksheet as proof of improved happiness.

Sharing links, exports and external services

Group setup links encode names and preferences in a URL fragment. A fragment is not sent in the normal HTTP request to UNISON's server, but anyone who receives the link can read its contents. Encoding is not encryption. Avoid sharing sensitive information.

Decision Reports and tentative calendar events are generated inside your browser and downloaded when you choose. They can contain names, favorites and votes, so review their contents before forwarding.

Clicking external Google Maps or Google Search links opens Google's service with a search for the Qloo-supplied venue name and location. These links are not authenticated venue pages or verified booking providers. Their privacy practices are independent of UNISON. UNISON does not claim to make bookings, verify opening hours or guarantee venue availability.

What does “Live Qloo” mean?

The status indicator checks whether the server has an API key configured. It does not guarantee that every Qloo Insights call will succeed or that each suggested venue is geographically correct. UNISON explains which evidence is observed and which scores are locally derived approximations.

Live mode is opt-in. The one-click demo and demo-mode recommendations never call Qloo endpoints.

Questions and source code

The public source is available on GitHub, so technical data flows can be reviewed. This information describes the current prototype; hosting providers and external services can have their own retention practices.
