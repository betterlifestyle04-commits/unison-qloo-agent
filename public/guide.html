02 / WHERE DATA COMES FROM

Know which evidence you're viewing.

UNISON separates editorial suggestions, simulated examples, and Qloo API results. They have different meanings.

EDITORIAL INPUT

Taste Inspiration

36 manually selected public cultural references to help fill in your group. They are not Qloo-confirmed entity IDs, popularity data, or recommendation scores.

  • Local search and selection only
  • No API request to browse
  • Optional input assistance
FICTIONAL DEMO

Explore the process

Deterministic fictional taste evidence illustrates how the decision logic works. It is not an authenticated Qloo Insights response.

  • No external Qloo API calls
  • Editable sample participants
  • Not evidence of real venues
LIVE QLOO

Observed taste signals

With live mode explicitly selected and a working server key, UNISON resolves cultural favorites and evaluates a shared shortlist using Qloo.

  • Server-only Qloo credential
  • Provenance and missing data visible
  • Not verified venue availability
♢

A configured key is not a successful API request. The status indicator means live requests can be attempted. The agent trace and optional connection check provide more specific evidence. Opening hours, addresses, bookings, prices and real-world satisfaction still require independent confirmation.

03 / READING YOUR SHORTLIST

A score is a clue, not a promise.

These are transparent project heuristics and group-decision aids—not validated probabilities of personal happiness.

↘

Lowest individual fit

The weakest observed relative-fit signal among people with evidence for that option. UNISON gives this more weight than a simple popularity average.

≈

Average fit

The average of known, locally estimated relative-fit values. A high group average can conceal a poorly supported participant.

◉

Evidence coverage

How many participants have an observed signal for a candidate. Missing evidence is unknown, not a negative opinion or group agreement.

✕

Veto and local votes

Participants can reject an option or mark Yes/Maybe/No on one browser. These do not modify Qloo's upstream evidence or create authenticated remote voting.

RECOMMENDATION-FIRST

What should I inspect first?

Read the top recommendation and shortlist, then open the evidence details. Check that all participants are represented before interpreting it as a supported compromise. For real outings, verify the location and booking facts yourself.

04 / QUESTIONS & ANSWERS

Answers without the guesswork.

Search product guidance or expand a question. This help search runs locally without tracking or API requests.

8 answers
How do I know if recommendations came from Qloo?

Choose Live Qloo explicitly, generate a plan, and read the source banner and execution trace. A server reporting “key present” means only that requests can be attempted. Demo results are always labeled fictional.

How many people and favorites can I add?

UNISON supports two to five people. Each needs a unique name and one to three cultural favorites. The optional Taste Inspiration panel contains 36 editorial examples; only live Taste Finder identifies official Qloo entities.

Does UNISON book tables or verify opening hours?

No. It recommends a shortlist and supplies external lookup links and a tentative calendar handoff. Venues, hours, addresses, price details, accessibility and reservations must be verified with the actual business before you go.

Where are saved plans stored and who can read them?

Saved briefs and summaries are stored only when you choose “Save on this device,” in that browser profile's local storage. Anyone using the profile may see them. Backups are unencrypted readable JSON. You can manage up to eight stored plans in My Workspace.

Are group links private or encrypted?

No. Copying a group setup link puts names and favorites into a URL fragment. The fragment isn't normally sent to UNISON in the HTTP request, but anyone who receives the link can read it. Use it only with trusted people.

Why might a shortlist have no fully supported winner?

Some participants may lack a matching Qloo signal for the same candidate. UNISON does not present incomplete evidence as full consensus. You can refine cultural favorites, broaden constraints, or deliberately submit a revised brief.

Can remote group members vote in real time?

Not currently. The Yes/Maybe/No controls support an in-person group using one browser. Votes do not sync across devices or authenticate individual users, and they do not alter Qloo's native signals.

Can I try UNISON without a Qloo key or account?

Yes. Demo mode requires no Qloo API key, and the application requires no account. The server returns deterministic fictional results so you can explore fairness, voting, and planning. Live requests require a configured, working Qloo key on the server.
